# September 2026

## Highlights

### New — Impact Analyzer: KB Compare and Compare PR

[Impact Analyzer](../agents/impact-analyzer.md) now has three workspaces:

- **Change Request Analysis** — the original flow
- **KB Compare** — reverse-engineers an application repository and a test-automation repository (zip upload or GitHub URL) into two knowledge graphs and compares them: coverage, uncovered components, APIs and journeys, obsolete automation and code-standards findings
- **Compare PR** — checks a change-request story against the change-request PR (**Document Comparison**) and the original PR against the CR PR (**PR Comparison**)

PR Comparison reports what was documented but not implemented, what was implemented but not documented, automation needing enhancement or newly required, customer-journey blast radius, historical defects to watch, and a traceability graph. Impacted tests now carry a **High / Medium / Low** level with a stated reason.

### New — Perf-Xi Frontend Analyzer

A fourth [Perf-Xi](../agents/perf-xi.md) mode that crawls a live application and audits **Web Vitals and frontend anti-patterns** — no scripts required. It supports an automated crawl and a human-in-the-loop session in which you browse the app yourself.

### New — Perf-Xi Greenfield workload engine and Script Maintenance

- Reworked **Greenfield** workload modelling with live progress, cancel, and explicit warnings when a document overrides a typed input
- **Script Maintenance** keeps an existing JMeter suite in step with API changes, new recordings, failed runs and sprint stories, through reviewable changesets

### New — Vantage (developer tool)

A dev-only live session view and control tool over Chrome DevTools Protocol, Android and iOS (Appium), with recording exported as a Playwright project, including optional API capture. See [Vantage](../agents/vantage.md). It is **not part of a deployed environment**.

### Improved — Auto-PlayPilot

- **API test automation**: select Web UI, API or both. API specifications (JSON/YAML) now actually reach the generator — previously every API test silently fell back to a generic template
- Combined frameworks: **Selenium + Rest Assured** (Java) and **Playwright UI + API** (JS/TS), with each test case routed to the UI suite, the API suite or both
- Rest Assured supports Cucumber BDD, tagged with the source test-case ID
- **Readable Report** — a per-step report for non-technical readers, with URLs redacted
- Selenium Java generates page objects, merging same-named classes rather than overwriting

### Improved — Visual Xi

- **Deterministic element matching** between Figma nodes and page elements, with a confidence floor and rejection of implausible matches
- Property comparison genuinely checks width, height, typography and colour
- Comparison reports **causes, not symptoms** — for example a width gap explained by letter spacing
- **Image-content scoring** catches the wrong product photo at the right size
- **Adjust Image** — shift a displaced section of the screenshot to realign it; saved per report
- Ignore regions scoped per run; tenant check fails closed
- Sector **Load sample** presets pair a Figma design with a mock site

### Improved — DeepSpeci

UI polish, a Figma connector on the Export panel, file-path mode and pasted-image upload on the input panel, document-type detection and signed score deltas on the quality dashboards.

### Improved — Defect Intelligence

A tracker and project picker on the manual and pipeline input screens; defect-sync status reads and transitions now require ownership.

### Improved — DataGeni

Guidewire vocabulary and Knowledge Base payload discovery, and generated rows now show which test case they came from.
