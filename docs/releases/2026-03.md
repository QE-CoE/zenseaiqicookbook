# March 2026

## Highlights

### New — Phase-3 backend (canonical persistence)

Introduced the Common Backend (Express 5, port 3001) with `pipeline_runs` and `agent_outputs` tables (Prisma + PostgreSQL). Previously all state lived in browser localStorage; now the backend is the source of truth and the frontend is a sync-friendly cache.

### New — Jira integration

DeepSpeci can pull requirements directly from Jira tickets via the Common Backend's per-tenant credential store.

### New — RIA (Requirements Intelligence Assistant)

Chat-first requirement intake for non-technical stakeholders.

### New — CaseGeni bulk priority edit

Test case priorities can now be bulk-updated from the table header.
