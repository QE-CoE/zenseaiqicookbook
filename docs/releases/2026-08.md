# August 2026

## Highlights

### New — Test Optimization agent

[Test Optimization](../agents/test-optimization.md) now works as a guided flow: **Upload → Overview → Duplicate → Similar → Optimized → Traceability**.

- Detects **duplicate** and **similar** test cases and suggests merges
- **AI rewrite** of weak tests
- Requirement and defect **traceability** on the optimised set
- Optional **semantic similarity** pass (capped at 600 test cases per run)
- Spreadsheet uploads moved to a library without known vulnerabilities; legacy `.xls` files are no longer accepted — save as `.xlsx` or CSV

### New — Visual Xi ported into the platform

[Visual Xi](../agents/visual-detector.md) joins the platform with Figma-to-live-page comparison, wired into pipelines. A sector-based **Load sample** option followed at the end of the month.

### New — Playwright Java with Cucumber BDD

[Auto-PlayPilot](../agents/auto-playpilot.md) generates a Maven project with Cucumber, JUnit 5, hooks, step definitions and a thread-safe page class. It executes through Maven and renders the Cucumber report inline. The UI blocks Playwright + Java without BDD because no execution path exists for it. Titles are escaped in generated Java and `pom.xml` files, and path traversal is closed.

### Improved — DeepSpeci requirement coverage

- Pasted specifications **without bullets** are no longer mostly dropped — a section recogniser recovers the structure
- The fixed acceptance-criteria cap is gone; the budget **scales with source complexity**
- Every number, amount, percentage and tier name in the source must survive into at least one acceptance criterion
- **Line-level coverage-gap detection**, and enumerated lists can no longer collapse into one generic criterion
- **Cross-project Jira push** — push refined stories to a Jira project other than the source
- Jira descriptions are carried separately from acceptance criteria, and acceptance-criteria extraction understands Jira's rich-text structure
- BFSI quality gate corrected (it had been running with the wrong security setting)

### Improved — CaseGeni

- **qTest push** sends per-step expected results as well as the overall expected result, with a **module-tree picker** for nested folders
- Accessibility (ADA/WCAG) is a recognised non-functional scenario type and carries the same risk weight as security when prioritising
- Precondition, test-case gap and end-to-end step fixes

### Improved — Impact Analyzer

- **Prioritised test plan** with tiers (Mandatory, High, Medium, Low, Exclusions), blending priority, linked defects and impact closeness; new tests can be approved or rejected
- **Jira export** of newly generated test cases (project picker, up to 500 per batch)

### Improved — Defect Intelligence

- Scoring, story-ID and defect-ID mapping, prioritised test plan ordering and gap counts corrected
- Jira bug-ticket workflow updated
- The auto-ingested lessons-learned knowledge base is scoped to BFSI

### Improved — Knowledge Graph

Integrated with the **Guidewire RAG** (Azure AI Search connector), and user-story ID formats in different styles now resolve correctly.

### Improved — Security

- **Secure-Xi**: bearer tokens masked, shared SSRF and target allow-list checks, ZAP API key moved to a header and required by the ZAP daemon, session state encrypted, report downloads bound to the owning tenant's run
- Backend hardening across the auth, error-handling and integration controllers following a VAPT/SAST review
- Frontend dependency advisories cleared; logout is now idempotent

### Platform — Podman removed

Databases and tools are now installed **natively** instead of in containers: PostgreSQL 16 (one server on `5432` holding both the platform and Knowledge Base databases), Neo4j 5 Community and OWASP ZAP. The Accessibility agent moved from port `8005` to **`8016`**. Developers on an earlier build should follow the migration steps in the repository (`docs/podman-removal-migration.md`) — stale `.env` values for the old ports must be removed.

## Fixed

- **Auto-PlayPilot** — self-heal retries never matched and falsely reported "Recovered"; the embedded Playwright report is restored and no longer deletes `results.json`
- **Pipeline** — Validate no longer silently does nothing on a cache miss, and Auto-PlayPilot depends on CaseGeni rather than on whatever precedes it
- **Knowledge Base** — restore no longer depends on database ownership and fails loudly on error; pasted credentials with trailing whitespace no longer look like a network outage
- **Install** — `install.sh` hardened for Windows (Python alias stubs probed, `.env` written atomically)
