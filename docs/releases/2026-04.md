# April 2026

## Highlights

### New — Per-tenant LLM routing

The Common Backend now resolves a tenant's encrypted LLM config (provider, model, API key) per-request and merges it into upstream agent calls. Raw API keys never reach the browser.

- AES-256-GCM at rest (`v1:iv:tag:ct` envelope)
- Just-in-time decryption — decrypted secrets live only in the request scope
- API responses expose only `apiKeyHint` masks

### New — Accessibility polished dashboard

The Accessibility agent now produces a **polished combined report** (`write-polished-dashboard.js`) suitable for sharing with stakeholders — WCAG breakdown, severity heatmap, AI-explained findings, downloadable PDF.

### New — DeepSpeci DOCX support

Requirements can now be uploaded as `.docx`, not only `.txt` / `.md`.

### Improved — CaseGeni edge case detection

Better heuristics for boundary cases on numeric ranges and string lengths.
