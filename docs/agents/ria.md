# RIA — Requirements Intelligence Assistant

> **Conversational requirement intake agent** — chat-first interface that helps non-technical stakeholders articulate requirements DeepSpeci can refine.

| | |
|---|---|
| **Port** | `8010` |
| **Stack** | Python · FastAPI |
| **Stage** | Requirements & Specs |
| **Downstream** | DeepSpeci |
| **Source** | `agents/ria/` |

## What it does

Stakeholder talks to RIA in plain English; RIA asks clarifying questions, captures decisions, and produces a clean requirement draft ready for DeepSpeci.
